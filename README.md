# Tunico — atualizacoes

Repositorio publico para **download** da extensao Tunico (Chrome).

- `update.json` — manifest de versao
- **Releases** — ZIP da extensao

## Instalacao

1. Baixe o ZIP da [ultima release](https://github.com/balbino13x-ctrl/tunico-releases/releases/latest)
2. Extraia a pasta `Tunico-3.0.0`
3. Chrome → `chrome://extensions` → Modo do desenvolvedor → Carregar sem compactacao
4. Recarregue o WhatsApp Web (F5)
